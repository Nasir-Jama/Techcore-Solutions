## Project Overview

This repository documents the design, implementation,
testing and security improvement of an enterprise network
for a fictional UK-based IT services company, TechCore
Solutions Ltd.

The project was developed using Cisco Packet Tracer and
will slowly be built and improved through a series of phases, starting with a functional
small-business network before introducing more advanced
enterprise networking and security technologies.

The objective is to demonstrate practical networking
skills through real configurations, network diagrams,
testing evidence and technical documentation.

## Business Scenario

TechCore Solutions Ltd. is a small IT services company
with 13 employees across three departments:

- Sales
- Finance
- IT

The company requires a reliable network infrastructure
to enable communication, shared server access, wireless
connectivity and internet access.

The network is developed in stages to support future
growth and stronger security.
